## 四、编号规则（避免以后再乱）

- **号段 = 写入时间**，不追求连续：01~17 是 RAG 阶段，18~24 是求职与学习阶段，25~27 是工程化阶段。
- **一个主题一个文件**；同一主题超过 3 份、且都只有几 KB 时，合并成一份并在文首写「由 N 份合并」+ 每节标「出处」。
- **合并后旧文件进 `archive/`**，不删——`docs/04` 与 `docs/22` 里可能还引用它们。
- **不再新增"临时稿"**：写之前先问自己"这是要长期维护的文档，还是一次性记录？"一次性记录写进 `04-工作日志.md`。
