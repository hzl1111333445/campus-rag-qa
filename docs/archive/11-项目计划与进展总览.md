## 三、已经做完的事（按链路）

### 1. 语料（数据层）

| 项 | 状态 |
|---|---|
| 文档数 | **33 份**（学籍类 11、学工类 6、图书馆 8、学生手册 8） |
| 文本块 | **643 块**，平均 239 字，**100% 已向量化**（bge-m3，1024 维） |
| 扫描件处理 | 14 份无文本层 PDF → 用 Windows OCR 转出 11 份（约 4 万字，单页 0.22 秒） |
| 缺口 | 食堂/校医院/公寓作息等学校未公开发布的，暂无法补（已在 docs/03 记录） |

### 2. 入库链路（文档进来）

上传 → Tika 解析（PDF/DOCX/TXT）→ 按句末切分（220 字 / 50 重叠）→ 块头加「文档标题·章节」→ 向量化 → 入 `kb_document` / `kb_chunk`

关键结果：**块数 748 → 305（-59%）、平均长度 99 → 195 字**（修掉「PDF 换行被当句子边界」导致的碎块）

### 3. 检索链路（核心，也是简历主打）

| 环节 | 实现 |
|---|---|
| 召回 | ①向量余弦（bge-m3）②BM25（手写，k1=1.5 / b=0.75，字+双字分词） |
| 融合 | RRF（k=60），支持权重（向量 0.2 / BM25 0.8） |
| 去重 | 同文档相邻块只留一个 |
| 精排 | Cross-Encoder（bge-reranker-v2-m3）取 Top-10 → 取 Top-3，不可用自动降级为 RRF |
| 展开 | 排序用单块，**给大模型看相邻三块** |

### 4. 生成与防幻觉层

- 提示词：6 条结构化规则（只依据资料 / 统一拒答话术 / 引用编号须真实 / 防注入 …）
- 检索层拒答：精排分阈值 **0.10**（可答题最低 0.1996、无答案题最高 0.0025，两组相隔 80 倍），拒答时**不调大模型**，响应 1.7s → 0.44s
- 引用校验：回答里的 `[n]` 必须 ≤ 资料条数
- 接地校验（groundedness）：抽数字+单位/时间点/处分名称，回原文核对，缺失即标黄

### 5. 评测体系（论文的骨架）

- 题集 **80 题**，第 6 列分 `dev`（42 道，调参用）/ `test`（36 道，只报最终数字）
- 9 种检索配置对比，指标 Recall@3 + MRR，按题型/划分拆解，漏题逐题归因

## 四、当前成绩（78 道有效题 × 643 块）

| 配置 | 总 Recall@3 | 总 MRR | dev | test |
|---|---|---|---|---|
| 纯向量 | 83.33% | 0.7051 | 85.71% | 80.56% |
| 纯 BM25 | 87.18% | 0.7991 | 92.86% | 80.56% |
| 混合 RRF | 91.03% | 0.8376 | 92.86% | 88.89% |
| 混合 + 精排 | 92.31% | 0.8504 | 92.86% | 91.67% |
| 合并相邻块 + 精排 | 94.87% | 0.8974 | 97.62% | 91.67% |
| **精排 + 展开邻居（线上）** | **97.44%** | **0.9167** | 97.62% | **97.22%** |

漏题仅 2 道：`#2 一年可以申请几次转专业`（跨块）、`#43 学业预警是怎么触发的`。

**可以对外说的一句话**：手写 BM25 + 向量双路召回，RRF 融合 + Cross-Encoder 精排，80 题评测集上 Recall@3 从 83%（纯向量）提升到 97%（线上链路），dev/test 仅差 0.4 个点。
