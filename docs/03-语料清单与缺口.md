### 已知"库里没有但对答案很关键"的坑
- **旷课多少学时会被处分** —— 学籍管理规定（54 条完好）里**没有**这一条，它写"按《学生学籍管理规定》执行"；
  而学籍规定本身不含学时标准 → 真正答案在**《学生考勤与请假管理办法》**，我们缺这份
- **宿舍能不能用大功率电器** —— 公寓管理规定缺失 → 只能退回《违纪处分条例》的"违章用电"条款，答不到具体功率和清单

## 四、补语料的操作流程（已经跑通，别再手工）

```powershell
# 1. 把新 PDF 丢进 docs-src\<分类>\
# 2. 判断是文本型还是扫描件
python tools\check-pdf-text.py

# 3. 扫描件：批量 OCR 成 txt
python "E:\tmp\ocr-test\ocr_batch.py"
#   → 输出到 docs-src-ocr\<分类>\*.txt

# 4. 上传入库（服务在 8090 或 8081）
curl.exe -F "file=@<txt路径>" http://127.0.0.1:8090/api/document/upload

# 5. 向量化新增块
curl.exe -X POST "http://127.0.0.1:8090/api/dev/embed-all?maxChunks=1000"
```
